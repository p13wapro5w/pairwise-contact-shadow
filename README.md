# pairwise-contact-shadow

角色贴墙站立时脚下浮出一圈断开的黑环，接触阴影射线在屏幕空间均匀发散，贴近表面的采样点全落在同一像素；步长按指数增长，脚踝处的接触瞬间丢失；厚度阈值按世界单位写死，远处角色被判定为完全遮挡；深度差比较没考虑符号，背面墙体的深度被当成遮挡物；法线偏移量固定，斜面出现漏光；半分辨率噪声没做时域累积，阴影表面爬满颗粒；TAA 历史直接沿用，角色抬脚后阴影粘在地上；透明物体写深度，玻璃后的接触阴影被错误截断；射线飞出屏幕边界后返回 1，画面边缘出现亮边；光源方向与屏幕空间射线不匹配，侧光下阴影偏到反方向。render/contact_shadow.py 是核心，tests/test_contact_shadow.py 15个红。要修的是：射线起点加像素级偏移；步长按屏幕距离自适应；厚度阈值随深度缩放；深度差带符号比较；法线偏移按视角缩放；半分辨率噪声做时域累积；移动物体重置历史；透明不写遮挡；出屏返回未遮挡；射线方向按光源投影。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
